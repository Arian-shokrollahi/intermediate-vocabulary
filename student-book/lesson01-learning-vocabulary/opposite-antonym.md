# opposite(antonym)
ا-**Kind**  
**ترجمه:** مهربان  
**تلفظ فارسی:** کایند

ا-**Opposite:** **Unkind / Mean**  
**ترجمه:** نامهربان / بدجنس  
**تلفظ فارسی:** اَن‌کایند / مین

--
ا-**Entrance**  
**ترجمه:** ورودی، محل ورود  
**تلفظ فارسی:** اِنترِنس

ا-**Opposite:** **Exit**  
**ترجمه:** خروجی، محل خروج  
**تلفظ فارسی:** اِگزیت

--
ا-**Dead**  
**ترجمه:** مرده  
**تلفظ فارسی:** دِد

ا-**Opposite:** **Alive**  
**ترجمه:** زنده  
**تلفظ فارسی:** اَلایو

--
ا-**Accept**  
**ترجمه:** پذیرفتن، قبول کردن  
**تلفظ فارسی:** اَکسِپت

ا-**Opposite:** **Reject / Refuse**  
**ترجمه:** رد کردن / نپذیرفتن  
**تلفظ فارسی:** رِجِکت / رِفیوز
